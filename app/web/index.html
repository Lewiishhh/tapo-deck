ABOUT THIS PLUGIN

Tapo Deck.

A local-first Stream Deck plugin for TP-Link Tapo smart bulbs.

Version 0.2.17.2
✦
WHAT IT DOES

Light control from your keys

Find supported Tapo bulbs on your home network, sign in locally, then assign Stream Deck keys to one or more selected bulbs. Keys can turn lights on or off, toggle them, set brightness or white temperature, and choose a color while preserving current brightness.

The plugin includes its local engine. It runs on this PC when Stream Deck needs it, so there is no separate companion app to keep open.

⌑
SECURITY & DATA

Designed to stay local

✓
Credentials stay on this PC

Windows DPAPI encrypts the saved Tapo sign-in for your Windows account. Tapo Deck sends it directly to bulbs for local authentication.

✓
No Tapo Deck cloud or telemetry

The plugin has no project-operated cloud, analytics, advertising, or remote-control relay. Device discovery and commands use your local network.

✓
Local engine connection

The helper listens on this PC only and uses a temporary authorization token. It stops when the Stream Deck plugin closes.

TP-Link's official Tapo app and any services it uses are operated separately by TP-Link and are outside Tapo Deck's control. Set up bulbs in the official phone app first.
