Tapo Deck Plugin 0.2.18.7 is the corrected Stream Deck SDK 3 build submitted for official Elgato Marketplace review. It is separate from the earlier 0.2.18 candidate that was withdrawn. This version adds a dedicated Save settings button alongside automatic local saving; the bundled engine confirms the local save and Stream Deck profile saving remains a best-effort mirror. The engine starts with the plugin and stops when the plugin exits. It includes draggable actions for power toggle, brightness, colour, and white temperature, plus the configurable control action. Requires Windows, Stream Deck 7.1 or later, compatible Tapo bulbs set up in the Tapo app, and bulbs switched on during discovery and sign-in.
